Christoffel's Menu
Christoffel's menu is a mobile app app designed for chef Christoffel to manage his restaurant menu.
The app designed to allow chef to add dishes, view all dishes, organised by course type, which allows to see total items added and average price.

The app consust of three screens:
1. Home Screen (index.tsx)
   >Display welcome message
   >Chef image for design
   >Display the total number of dishes in menu
   >Buttons for view and add menu
   
   2. Add Menu Screen (explore.tsx)
      >Input fields for:
      - Dish name
      - description
      - Price
      >Course selection
      - Starter
      - Main
      - Dessert
      > Erro handling for all input fields must be filled and displays massage if dish added successfully
      
      3. View Menu Screen
         > Display all menu items in cards as follows:
         - Dish name
         - Course tag
         - Description
         - Price
         > Total and average calculation
